# الحلو شات

تطبيق مراسلة مستقل. المستودع يحتوي حالياً على واجهة ويب عربية قابلة للتثبيت كـ PWA ومعاينة محلية للواجهات.

## الحالة الحالية
- واجهة الهاتف: موجودة.
- PWA manifest وأيقونة وغلاف offline: موجودة.
- API status: يوضح أن خدمات الخادم غير مهيأة.
- واجهة اختيار Google وFacebook ورقم الهاتف: موجودة للمعاينة فقط.
- ربط Google OAuth وFacebook OAuth وإرسال SMS OTP: لم يُفعّل بعد؛ يلزم إعداد بيانات التطبيقات والمفاتيح السرية على الخادم.
- الحسابات، قاعدة البيانات، البحث الحقيقي، مطابقة جهات الاتصال، الرسائل الفورية، الإشعارات والتشفير: لم تُفعّل بعد.

## البنية المطلوبة قبل فتح التسجيل العام
1. قاعدة بيانات مستقلة للمستخدمين والمحادثات والرسائل والأجهزة.
2. مزود SMS موثوق لإرسال OTP مع تحديد المعدل ومنع إساءة الاستخدام.
3. جلسات مصادقة آمنة.
4. مطابقة جهات الاتصال بموافقة صريحة وبآلية لا تكشف دفتر العناوين.
5. قناة رسائل فورية وإشعارات Push.
6. تصميم تشفير طرف لطرف مُراجع أمنياً قبل وصف التطبيق بأنه مشفر.

لا تضع مفاتيح أو أسرار داخل ملفات الواجهة أو Git. افتح /api/status لمعرفة حالة تجهيز الخادم. حالياً backendReady=false عمداً حتى لا تظهر الواجهة وكأنها نظام مراسلة حقيقي.
